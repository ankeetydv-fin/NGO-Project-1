# NGO / Foundation Website Brief

This document is the single source of truth for building a full NGO/foundation website inspired by trustworthy nonprofit sites such as Smile Foundation and Akshaya Patra.

---

## 1) Project Goal

Build a modern, emotionally resonant, trust-first NGO website that:

- explains the organization’s mission clearly
- builds credibility and transparency
- encourages donations and volunteering
- showcases real impact through stories, numbers, and reports
- remains easy for NGO staff to update later

The website should feel:

- trustworthy
- human
- warm
- professional
- accessible
- clean
- non-corporate

It should not feel like a generic startup site.

## 4) Color System

### Primary colors
Use a calm, trustworthy palette.

#### Suggested base palette
- Primary Blue: `#1E4E8C`
- Secondary Teal: `#0F766E`
- Accent Orange: `#F59E0B`
- Accent Green: `#16A34A`
- Background Off-White: `#F8FAFC`
- Surface White: `#FFFFFF`
- Text Dark: `#0F172A`
- Text Muted: `#475569`
- Border Light: `#E2E8F0`

### Usage rules
- Blue for trust, links, navigation, headings, and primary branding
- Orange for donation or high-priority CTA only
- Green for success, impact, and positive outcomes
- Off-white backgrounds for readability
- Avoid overly saturated gradients
- Avoid neon colors
- Avoid too many brand colors competing with each other

### CTA hierarchy
- Primary CTA: strong filled button
- Secondary CTA: outline button
- Tertiary CTA: text link

### Example CTA usage
- Donate Now
- Become a Volunteer
- Read Impact Report
- Explore Programs

---

## 5) Typography System

### Font direction
Choose a modern, highly readable sans-serif family.

### Suggested pairing
- Headings: `Poppins`, `Inter`, or `Manrope`
- Body: `Inter` or `Source Sans 3`

### Typography rules
- headings should be bold and clear
- body text should be comfortable for long reading
- line-height must be generous
- avoid decorative fonts
- avoid low-contrast text

### Scale suggestion
- H1: 48–64px desktop, 32–40px mobile
- H2: 32–44px desktop, 24–32px mobile
- H3: 24–28px desktop, 20–24px mobile
- Body Large: 18px
- Body: 16px
- Small: 14px

### Typography tone
- headlines should inspire action
- body copy should be simple and direct
- statistics should be bold and easy to read

---

## 6) Spacing and Layout Rules

### Spacing
- use an 8px spacing system
- section padding: 80–120px desktop, 48–72px mobile
- card padding: 20–32px
- consistent vertical rhythm

### Container widths
- max content width: 1200px to 1280px
- avoid full-width text blocks
- use centered containers for readability

### Grid system
- 12-column grid desktop
- 2-column or 1-column layout on mobile
- cards should align consistently
- always maintain visual balance

## 9) Home Page Information Architecture

### Section order

2. Hero section
3. Trust bar / partner logos
4. Mission statement
5. Impact statistics
6. Programs preview
7. Donation CTA section
8. Real stories / testimonials
9. Transparency / report section
10. Volunteer section
11. Latest articles or updates
12. Footer

### Homepage objective
The homepage must answer these questions fast:
- Who are you?
- What do you do?
- Whom do you help?
- Why should people trust you?
- How can people donate or help?

## 10) UX Rules

### Navigation
- simple top nav
- sticky header on scroll
- clear donate button
- fewer menu items
- no clutter

### User flow priorities
- donate quickly
- understand mission quickly
- find reports quickly
- find volunteer info quickly
- contact easily

### Trust UX
- show impact numbers early
- show real beneficiaries
- show reports and certificates
- show partner logos
- show transparent outcomes

### Accessibility rules
- strong contrast ratios
- keyboard navigable
- visible focus states
- alt text for all images
- semantic headings
- readable font sizes
- usable without animation

---

## 11) Motion Guidelines

### Motion style
- subtle
- smooth
- short duration
- not distracting

### Allowed motion
- fade in
- slide up on scroll
- hover lift on cards
- soft button transitions

### Avoid
- aggressive parallax
- heavy bouncing
- overly complex animations
- large motion on every section

---

## 12) Imagery Guidelines

### Image style
- real photographs of people, communities, events, children, volunteers, field work
- consistent aspect ratios
- warm natural light when possible
- authentic emotion
- avoid stock-photo stiffness

### Media usage
- use image cards for stories
- use banners for campaigns
- use galleries for event coverage
- keep images compressed and optimized
